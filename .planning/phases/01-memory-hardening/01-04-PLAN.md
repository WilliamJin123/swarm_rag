Focus on `_run_agents_on_graph()` method (the main single-query traversal):

```python
# Replace:
position_history = torch.full((n_agents, steps + 1), -1, device=self._device, dtype=torch.long)

# With:
if self._buffer_pool is not None:
    position_history = self._buffer_pool.get_position_buffer(n_agents)

    # Expand for steps if needed - position_history is (n_agents,) but we need (n_agents, steps+1)
```

Focus instead on the PER-STEP allocations in `_step_agents_batched()`:
- Line 1341: `total_scores = torch.zeros_like(semantic_scores)` - This is fine, uses zeros_like
- Line 1377: `chosen_positions = torch.zeros(n_agents, ...)` - Can use buffer pool

For `_step_agents_batched()`:
```python
# At line 1377, replace:

if self._buffer_pool is not None:

    chosen_positions = torch.zeros(n_agents, dtype=torch.long, device=device)
```

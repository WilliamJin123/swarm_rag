  <name>Task 1: Create MemoryGuard context manager with threshold enforcement</name>
  <files>swarm_rag_module/swarm_rag/evolution/execution/memory_guard.py</files>
  <action>
Create a new module `memory_guard.py` with:

1. `MemoryThresholdExceeded(Exception)` - Custom exception for hard stop threshold breach

2. `MemoryGuard` context manager class:
   - Constructor params:
     - `warning_threshold: float = 0.70` (70% of VRAM)
     - `hard_stop_threshold: float = 0.85` (85% of VRAM)
     - `cleanup_on_exit: bool = True`
     - `label: str = ""` (for logging identification)
   - `__enter__`:
     - Record `_before_allocated = torch.cuda.memory_allocated()` if CUDA available
     - Record `_total_vram = torch.cuda.get_device_properties(0).total_memory`
     - Return self
   - `__exit__`:
     - If not CUDA available, return False
     - Compute `after_allocated = torch.cuda.memory_allocated()`
     - Compute `delta = after_allocated - self._before_allocated`
     - Compute `usage_ratio = after_allocated / self._total_vram`
     - If `usage_ratio >= hard_stop_threshold`:
       - Raise `MemoryThresholdExceeded` with detailed message including usage_ratio, threshold, delta, label
     - If `usage_ratio >= warning_threshold`:
       - Log warning with same details
     - If `cleanup_on_exit`:
       - `gc.collect()`
       - `torch.cuda.empty_cache()`
     - Return False
   - Properties:
     - `delta_bytes` -> int (after - before)
     - `delta_mb` -> float
     - `usage_ratio` -> float (current / total)

3. Read thresholds from environment variables if set:
   - `MEMORY_WARNING_THRESHOLD` (default 0.70)
   - `MEMORY_HARD_STOP_THRESHOLD` (default 0.85)

Use `@torch.no_grad()` is NOT appropriate for context manager (it's a decorator). Instead, the guard just tracks memory; callers wrap their code in `torch.no_grad()` separately.

Import: `import gc`, `import os`, `import torch`, `import logging`

```python
def evaluation_no_grad(
    track_memory: bool = True,
    warning_threshold: float = None,
    hard_stop_threshold: float = None
):
    """
    Decorator for genome evaluation functions.

    Combines torch.no_grad() context with optional MemoryGuard tracking.

    Usage:
        @evaluation_no_grad(track_memory=True)
        def evaluate_genome(genome, ...):
            # All operations are gradient-free
            # Memory is tracked and cleaned up
            pass
    """
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            with torch.no_grad():
                if track_memory and torch.cuda.is_available():
                    warn_thresh = warning_threshold or MEMORY_WARNING_THRESHOLD
                    stop_thresh = hard_stop_threshold or MEMORY_HARD_STOP_THRESHOLD
                    with MemoryGuard(
                        warning_threshold=warn_thresh,
                        hard_stop_threshold=stop_thresh,
                        label=func.__name__
                    ):
                        return func(*args, **kwargs)
                else:
                    return func(*args, **kwargs)
        return wrapper
    return decorator
```

Refactor the existing `AsyncCheckpointWriter` class (lines 25-166) to implement CONTEXT.md decisions:

**Threading Model:**
- Change `Queue(maxsize=1)` to `Queue()` (unbounded) - queue all checkpoints
- Change `daemon=True` to `daemon=False` - allow graceful shutdown
- Use sentinel value (None) for shutdown signal instead of Event
- Remove the drop-stale-checkpoint logic in `save()` method

**Data Consistency (add new method):**
- Add `_prepare_checkpoint_data(state: dict) -> dict` method
- Deep copy all checkpoint data before queuing
- Handle tensors: `tensor.detach().clone().cpu()`
- Handle genomes: use `.copy()` method if available
- Handle nested dicts/lists recursively

**Atomic Writes (update `_write_checkpoint`):**
- Use `tempfile.mkstemp(suffix=".tmp", prefix="ckpt_", dir=checkpoint_dir)`
- Close fd from mkstemp before torch.save
- Use `os.replace(temp_path, target_path)` instead of `os.rename`
- Clean up temp file in except block if write fails
- Save to BOTH gen_path and latest_path with atomic pattern

**Retry Logic (add to `_write_checkpoint`):**
- Retry once on failure with 0.5s delay
- Log warning on retry: "Checkpoint write failed (attempt N), retrying..."
- Log error after final failure: "Checkpoint write failed after N attempts"
- Return bool success status

**Logging/Stats:**
- Add `CheckpointStats` dataclass with: total_saves, total_time_seconds, total_bytes
- On queue: log "Checkpoint queued (gen N)"
- If queue depth > 1: log warning "Checkpoint queue: N pending"
- On complete: log "Checkpoint saved (gen N, X.XMB, X.XXs)"
- On shutdown: log "Checkpointing: N saves, Xs total, avg Ys"

**Shutdown:**
- Rename `shutdown()` to `shutdown(timeout: float = 30.0) -> bool`
- Put sentinel (None) to queue
- Join thread with timeout
- Log summary stats
- Return True if clean shutdown, False if timeout

**Remove:**
- Remove `_cleanup_old_checkpoints` method (per CONTEXT: keep all checkpoint files)
- Remove `_keep_n` parameter and related logic
- Remove `flush()` method (shutdown handles drain)

Import additions at top:

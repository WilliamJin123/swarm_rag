  <action>
Create fitness_cache.py with:

1. Add xxhash to requirements.txt (pip install xxhash)

2. Implement hash_genome(genome: Genome) -> str:
   - Hash ALL fields that affect retrieval behavior:
     - mode (GenomeMode enum -> .value string)
     - params (all hyperparameters)
     - group_ratios (agent distribution)
     - strategies (expression trees, via to_dict())
     - weight_tensors (weighted sum mode, via to_dict())
   - Round floats to 6 decimal places before hashing (handles FP noise)
   - Use json.dumps(sort_keys=True, separators=(',', ':')) for canonical serialization
   - Return xxhash.xxh64_hexdigest(canonical.encode('utf-8'))
   - DO NOT hash: id, fitness, metrics, evaluated, latency (metadata, not config)

3. Implement CacheStats dataclass:
   - hits: int = 0
   - misses: int = 0
   - Properties: total, hit_rate
   - reset() method

4. Implement FitnessCache class:
   - _cache: Dict[str, float] (hash -> quality_score)
   - _generation_stats: CacheStats (reset each generation)
   - _total_stats: CacheStats (cumulative)
   - get(genome) -> Optional[float]: lookup, increment stats
   - put(genome, fitness_score: float): store
   - finalize_generation(generation: int) -> CacheStats: log and reset per-gen stats
   - size property: len(_cache)

5. Export FitnessCache and hash_genome from __init__.py

Key decisions from CONTEXT.md:
- In-memory only (no disk persistence)
- Store just fitness score (single float per entry)
- No thread locks (evolution is synchronous)
- Unlimited cache size (fitness floats are tiny, ~25K max entries)

Modify PopulationEvaluator to use FitnessCache:

1. Add import: from .fitness_cache import FitnessCache

2. In __init__:
   - Add self._fitness_cache = FitnessCache()

3. In evaluate() method, BEFORE the main evaluation loop:
   - After filtering unevaluated genomes, check cache for each:
   ```python
   cache_restored = []
   still_unevaluated = []
   for genome in unevaluated:
       cached_fitness = self._fitness_cache.get(genome)
       if cached_fitness is not None:
           # Restore from cache without re-evaluation
           genome.fitness = FitnessResult(quality_score=cached_fitness)
           genome.evaluated = True
           cache_restored.append(genome)
       else:
           still_unevaluated.append(genome)
   unevaluated = still_unevaluated
   ```

4. After evaluation completes (where genome.fitness is assigned):
   - Add cache put for each newly evaluated genome:
   ```python
   self._fitness_cache.put(genome, genome.fitness.quality_score)
   ```
   - This goes in _evaluate_single_full, _evaluate_single_full_with_shared,
     and the early exit path in _evaluate_single/_evaluate_single_with_early_exit

5. At the end of evaluate() method, before returning stats:
   - Add: self._fitness_cache.finalize_generation(generation_number)
   - Note: evaluate() doesn't receive generation number, so store it as instance state
     or extract from a passed-in context. Simplest: add optional generation param to evaluate()

Key constraint: Cache stores ONLY quality_score (float). Stability score is deterministic
from metrics, so we only need quality_score for cache hits. When restoring from cache,
create FitnessResult with just quality_score (stability will be 0 but that's fine for
cache hits since we don't re-rank elites by stability).

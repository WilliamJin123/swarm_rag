<objective>
Persist query embeddings across generations to eliminate redundant embedding computation.

Purpose: Query embeddings are identical across generations (same query set). Currently `prepare_shared_context()` recomputes them every generation. By persisting in the global `EmbeddingCacheProvider`, we skip embedding computation after generation 1, achieving 50-80% retrieval savings.

Output:
- Enhanced `QueryEmbeddingCache` with per-generation stats and time-saved tracking
- `prepare_shared_context()` integrated with global embedding cache
- `MemoryLogger` extended with embedding cache stats (mirrors FitnessCache pattern)
- Evolution cleanup wiring in evaluator
</objective>

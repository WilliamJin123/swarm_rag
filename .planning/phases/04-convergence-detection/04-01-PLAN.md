**detector.py:**
- Create `TerminationReason` enum with values: MAX_GENERATIONS, CONVERGENCE, MEMORY_LIMIT, USER_INTERRUPT
- Create `ConvergenceDetector` class with:
  - `__init__(self, config: ConvergenceConfig)` - initialize deque(maxlen=window_size), generation counter, last_improvement_gen
  - `record(self, qd_score: float)` - append to window, track improvement, adapt window size if enabled
  - `is_converged(self) -> bool` - check grace period, check window has sufficient data, call _check_stagnation()
  - `_check_stagnation(self) -> bool` - calculate improvement ratio (max-min)/min, compare against relative threshold
  - `_calculate_threshold(self, current_score: float) -> float` - base threshold adjusted by headroom if theoretical_max set
  - `_adapt_window_size(self)` - expand when improving (gens_since_improvement < 5), shrink when flat (> 15)
  - `get_stats(self) -> Dict[str, Any]` - return generation_count, window_size, window_min/max, last_improvement_gen, etc.
  - `get_window_stats(self) -> str` - human-readable summary for logging

Key implementation details:
- Use `collections.deque(maxlen=N)` for O(1) sliding window operations
- Log stagnation detection with improvement ratio and threshold values
- Preserve window data when resizing (convert to list, create new deque)
- Handle edge cases: window_min <= 0 returns False (avoid division issues)

**__init__.py:**
- Export: ConvergenceConfig, ConvergenceDetector, TerminationReason
